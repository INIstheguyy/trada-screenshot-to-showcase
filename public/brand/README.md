# Trada brand assets

- `trada-logo.png`: transparent full logo lockup, lossless fallback.
- `trada-logo.webp`: transparent full logo lockup for normal web use.
- `trada-mark.png`: transparent 1024px standalone symbol for design and application use.
- `trada-mark.webp`: optimized standalone symbol for normal web use.

Use the full logo where the tagline remains readable. Use the standalone mark for compact controls, avatars, application icons and square placements.
